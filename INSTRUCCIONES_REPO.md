## 🛠 Cómo actualizar la web correctamente

Para que los cambios se vean reflejados en internet, debes seguir estos pasos en la terminal **dentro de esta carpeta**:

### 1. Preparar los archivos
Añade los archivos que hayas modificado:
```bash
git add .
```

### 2. Crear el "paquete" de cambios (Commit)
Escribe un mensaje corto que explique qué cambiaste:
```bash
git commit -m "Explicación de lo que hiciste (ej: rebranding oris y axis)"
```

### 3. Subir a la nube (Push)
Envía los cambios a GitHub para que Vercel actualice la web:
```bash
git push origin main
```
